# Competitor gap (Elena Brooks)

1. **Who ranks:** for each target keyword (`marketing/seo/target-keywords.md`) record the top organic and Map Pack competitors from a tool that shows the live SERP (Semrush `organic_research`/`competitors_research` when units exist, or a page fetch of public results if allowed). Name the source and date; if no tool can see the SERP, say so.
2. **Compare per competitor:** pages for the keyword/area (fetch their public page), on-page basics (`Local_SEO` `check_local_page` on their URL), content depth and FAQs, review count/rating as shown publicly, referring domains (Semrush `backlinks_research` / Ahrefs if available).
3. **Gap list:** missing pages/topics → Maya; missing citations → Hannah (respect `newCitationsBlocked`); link sources they have that we could earn → Natalie (`marketing/backlinks/opportunities-tracker.csv`); review gap → `review-engine`.
4. Write `marketing/seo/competitor-gap-YYYY-MM.md`. Never copy competitor text; write our own from our facts.

Apply `marketing/unslop-style.md` to anything that ships.
